# excel_map.md

# Карта Excel для расчёта линейной арматуры

## 1. Назначение файла

Этот файл объясняет Codex, как использовать Excel-файл `armature_calc.xlsx` для расчёта арматуры и материалов по готовому плану ВЛ.

Главный лист для расчёта:

```text
Линейная арматура
```

Принцип работы листа простой:

```text
слева — материал / арматура
сверху — тип опоры
на пересечении — количество материала на одну опору этого типа
```

Пример:

```text
строка F207
столбец П23
значение 2
```

Это означает:

```text
на одну опору П23 нужно 2 единицы F207
```

Если на плане найдено 5 опор П23, то вклад П23 в F207:

```text
5 * 2 = 10
```

---

## 2. Исходные данные для расчёта

Программа получает исходные данные из `plan_data.json`, `tu_data.json` и `project_data.json`.

### 2.1. Данные из плана

```text
{{P23}} = количество опор П23
{{A23}} = количество опор А23
{{YA23}} = количество опор УА23*
{{K21}} = количество опор К21
{{GROUND}} = количество заземлений
{{LINE_LENGTH_M}} = длина линии, м
{{LINE_LENGTH_KM}} = длина линии, км
```

### 2.2. Данные из ТУ

```text
{{FAZE}} = фазность: однофазный / трехфазный
{{SECH_KABEL}} = сечение кабеля: 3x70+1x70 / 3x50+1x50
```

## 3. Лист «Линейная арматура»

### 3.1. Расположение таблицы

В файле `armature_calc.xlsx` используется лист:

```text
Линейная арматура
```

Основная матрица находится в диапазоне:

```text
A5:J24
```

Строки с материалами:

```text
A9:A24
```

Столбцы с типами опор:

```text
C:J
```

---

## 4. Столбцы типов опор

В листе `Линейная арматура` типы опор расположены так:

```text
C = П23
D = П23доп
E = УП21
F = А23
G = АО23
H = К21
I = УА21
J = УА23*
```

Для текущего MVP используются основные типы:

```text
C = П23    -> {{P23}}
F = А23    -> {{A23}}
H = К21    -> {{K21}}
J = УА23*  -> {{YA23}}
```

Остальные типы можно добавить позже:

```text
D = П23доп
E = УП21
G = АО23
I = УА21
```

---

## 5. Общая формула расчёта по матрице

Для обычных материалов формула такая:

```text
Количество материала =
{{P23}} * коэффициент_П23
+ {{A23}} * коэффициент_А23
+ {{K21}} * коэффициент_К21
+ {{YA23}} * коэффициент_УА23
```

Где коэффициенты берутся из листа `Линейная арматура` на пересечении строки материала и столбца типа опоры.

## 7. Placeholder-формулы для записки

### 7.1. Количество опор

```text
{{P23}} = количество блоков П23 на плане
{{A23}} = количество блоков А23 на плане
{{YA23}} = количество блоков УА23* на плане
{{K21}} = количество блоков К21 на плане
```

Общее количество опор:

```text
{{S}} = {{P23}} + {{A23}} + {{YA23}} + {{K21}}
```

---

### 7.2. Заземления

```text
{{GROUND}} = количество блоков заземления на плане
{{GR}} = {{GROUND}} * 3
```

---

### 7.3. Бетон по типам опор

```text
{{P23_1}} = {{P23}} * 0.36
{{YA231}} = {{YA23}} * 0.9
{{K21_1}} = {{K21}} * 0.45
```

Общая масса бетона:

```text
{{S1}} = {{P23_1}} + {{YA231}} + {{K21_1}}
```

Примечание: для А23 отдельная бетонная формула пока не задана. Если потребуется учитывать А23 в массе бетона, нужно добавить отдельный placeholder.

---

### 7.4. Стойки СВ110-5

Placeholder:

```text
{{5}}
```

Формула:

```text
{{5}} = {{K21}} * 1 + {{YA23}} * 2
```

Масса бетона для стоек СВ110-5:

```text
{{51}} = {{5}} * 0.45
```

---

### 7.5. Стойки СВ95-3

Placeholder:

```text
{{3}}
```

Формула:

```text
{{3}} = {{P23}} * 1 + {{A23}} * 2
```

Масса бетона для стоек СВ95-3:

```text
{{31}} = {{3}} * 0.36
```

---

### 7.6. Длина кабеля с запасом

```text
{{LINE_LENGTH_KM}} = {{LINE_LENGTH_M}} / 1000
{{SECH_KM}} = {{LINE_LENGTH_KM}} * 1.045
```

---

### 7.7. Масса кабеля

```text
если {{SECH_KABEL}} = 3x70+1x70:
{{SECH_KG}} = {{SECH_KM}} * 1112

если {{SECH_KABEL}} = 3x50+1x50:
```


## 9. Сечение кабеля и провода

### 9.1. Сечение кабеля из ТУ

```text
если в ТУ написано "сечением кабеля до 50":
{{SECH_KABEL}} = 3x50+1x50

если в ТУ написано "сечением кабеля от 50 до 70":
{{SECH_KABEL}} = 3x70+1x70
```

Возможные варианты написания, которые программа должна воспринимать одинаково:

```text
3x70+1x70
3х70+1х70
3 x 70 + 1 x 70
3х50+1х50
3x50+1x50
```

---

### 9.2. Сечение СИП-4 по фазности

```text
если {{FAZE}} = трехфазный:
{{SECH_SIP4}} = 4x16

если {{FAZE}} = однофазный:

```

## 11. Что должен сделать Codex

Codex должен реализовать отдельный модуль расчётов, например:

```text
core/material_calculator.py
```

Модуль должен:

1. получить данные из `plan_data.json`;
2. получить данные из `tu_data.json`;
3. посчитать все формулы из этого файла;
4. сформировать `materials_data.json`;
5. передать готовые значения в `replacement_map.json`.

## 14. Важные замечания

1. В Excel строка называется `ES1500E`, а в шаблоне используется `{{ES15}}`.
2. В Excel строка называется `CS10.3`, а в шаблоне используется `{{CS10}}`.
3. В Excel строка называется `PA1500`, а в шаблоне используется `{{PA15}}`.
4. Placeholder `{{5}}` означает количество стоек СВ110-5.
5. Placeholder `{{3}}` означает количество стоек СВ95-3.
6. Placeholder `{{51}}` означает массу бетона для СВ110-5.
7. Placeholder `{{31}}` означает массу бетона для СВ95-3.
8. Все числовые результаты желательно округлять только на этапе вывода в записку.
9. В расчётах внутри программы лучше хранить числа без преждевременного округления.
10. Если в ТУ или плане не хватает данных, программа должна показать ошибку и не молча подставлять нули.
