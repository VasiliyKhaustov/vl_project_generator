Как открыть PRO на Linux
=========================

1. Установите Python 3.11 или новее и venv.
   Debian/Ubuntu: sudo apt install python3 python3-venv python3-pip
2. Для чертежей DWG/DXF установите ODA File Converter.
   Программа ищет его здесь:
   /usr/local/bin/ODAFileConverter
   /usr/bin/ODAFileConverter
   Либо укажите путь в config/settings.json, поле oda.linux_exec_path.
3. В терминале из этой папки:
   ./start.sh
   Либо дважды щёлкните «Открыть PRO.desktop».
   Если система не даёт запустить ярлык, в терминале выполните:
   chmod +x start.sh "Открыть PRO.desktop"
   gio set "Открыть PRO.desktop" metadata::trusted true
4. Откроется браузер: http://127.0.0.1:8003
5. Остановка: Ctrl+C в окне терминала.

Повторный запуск просто открывает страницу, если сервер уже работает.
